Change in improvement over the unintegrated baseline per shared orthologue for each input, estimated within each tissue (+MAP +SAS), for the overall, bio-conservation and batch-correction scores. Points: slope from a separate model for each tissue (input, number of shared orthologues, algorithm and algorithm by input as fixed effects; random effects for dataset and dataset by input; Kenward--Roger degrees of freedom), for the six algorithms run on all three inputs. Bars: the common slope from the model across all tissues (Section~\ref{sec:stats_orthologues}). A larger slope means that the input loses more improvement as shared orthologues are removed.
